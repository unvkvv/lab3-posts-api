# Лабораторная работа № 3 — Доска публикаций

**Дисциплина:** Клиентские скрипты  
**Тема:** Асинхронный JavaScript и REST API  
**Выполнила:** Новикова У. А., БПИ-23-РП-2

## Реализованные функции

- Загрузка пяти публикаций по GET-запросу с `fetch`, `async/await`, проверкой `response.ok` и разбором JSON.
- Динамическое создание карточек публикаций через DOM и `textContent`.
- Форма с полями «Заголовок» и «Текст»; проверка пустых строк и строк из пробелов.
- Отправка POST с `Content-Type: application/json` и телом `{title, body, userId: 1}`.
- Показ заголовка и ID из ответа, а также статуса успешной отправки.
- Сообщения «Загрузка…»/«Отправка…», обработка сетевых ошибок и HTTP 404, повторная попытка.
- Блокировка соответствующей кнопки на время запроса без перезагрузки страницы.

## Сценарии проверки и ожидаемый результат

1. Нажать **«Загрузить публикации»**: при доступности API отображаются **5** записей и сообщение об успешной загрузке (HTTP 200).
2. Нажать **«Создать публикацию»** с пустыми полями или пробелами: выводится понятная ошибка, POST-запрос не выполняется.
3. Указать заголовок `Новости университета` и текст `Завершена лабораторная работа № 3.`; отправить: при доступности API сервер обычно возвращает **HTTP 201** и **ID 101**, ответ отображается на странице. JSONPlaceholder не сохраняет новую запись постоянно.
4. Для проверки 404 изменить в `app.js` значение **POSTS_GET_URL** на `https://jsonplaceholder.typicode.com/postz`; сохранить файл и нажать «Загрузить публикации»: появляется сообщение **HTTP 404**, после завершения запроса кнопка активна. **Обязательно восстановить исходный адрес** `https://jsonplaceholder.typicode.com/posts?_limit=5`, сохранить и повторить успешную загрузку.
5. При отключённом интернете приложение показывает сообщение о сетевой ошибке и позволяет повторить запрос после восстановления подключения.
